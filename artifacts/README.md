# Development evidence

Written review reports are versioned here. Generated screenshots, check logs,
build trees, and exported conversation records remain local and are ignored by
Git. Reports may reference those local files or localhost demonstration links.

Scripts under `dev/` generate many of these artifacts. Some history verification
scripts require saved records from an interactive demonstration; those records
are not included in a fresh clone. The package tests under `tests/` are
self-contained and do not depend on this directory.
